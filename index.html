    Aislamiento

    Si f es continua y f(a)·f(b) < 0, el teorema del valor intermedio garantiza al menos una raíz dentro de [a, b]. Ese es el permiso que necesitan bisección y falsa posición, y el punto de partida razonable para los métodos abiertos.

    Un paso grande puede saltarse dos raíces juntas y no ver ningún cambio de signo. Si sospechas que falta alguna, redúcelo.

    Herramienta 03

    Fórmulas y criterios

    La ficha de referencia: qué calcula cada método, cuándo tiene derecho a converger y cuándo se le permite parar.

    Criterio de parada

    Error relativo porcentual aproximado εa = | (xnuevo − xanterior) / xnuevo | × 100 %
    se detiene cuando εa < εs

    El criterio no mide el error real (la raíz exacta es desconocida), sino cuánto se movió la estimación entre dos pasos. Por eso siempre falta la primera fila: sin un valor anterior no hay diferencia que medir.

    Criterio de Scarborough — cifras significativas garantizadas εs = ( 0.5 × 10(2 − n) ) %

    Las tareas de la semana 2 usan εs = 0.5 % → 2 cifras significativas. La semana 3 usa εs = 0.01 %, entre 3 y 4 cifras.

    Métodos cerrados Bracketing

    Encierran la raíz entre dos extremos y estrechan el intervalo. Exigen f(xL) · f(xU) < 0 y a cambio siempre convergen.

    Métodos abiertos Open

    Arrancan de uno o dos valores sin encerrar la raíz. Son más rápidos, pero pueden diverger.

    Orden de convergencia

    Con orden p, el error nuevo es proporcional al error anterior elevado a p. Orden 2 (Newton) duplica aproximadamente las cifras correctas en cada paso; orden 1 (bisección, punto fijo) las gana de forma constante y lenta.

    Sesión 4 · Raíces de polinomios

    Análisis de un polinomio

    Cuatro pasos antes de iterar a ciegas: dónde pueden estar las raíces, cuántas hay de cada signo, cuáles salen exactas por división sintética, y las que quedan —incluidas las complejas— con el método de Müller.

    El polinomio

    Escríbelo entero (x^4 + x^3 - 3x^2 - x + 2) o solo los coeficientes de mayor a menor grado (1, 1, -3, -1, 2).
