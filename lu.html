    Sesión 7 · Métodos iterativos

    Método de Gauss-Seidel

    También aísla cada incógnita en su propia ecuación, pero a diferencia de Jacobi, actualiza de inmediato: al calcular x2 ya usa el x1 recién obtenido en la misma iteración, y así sucesivamente. Esta actualización secuencial suele converger más rápido que Jacobi.

    1 · Sistema Ax = b

    2 · Despejar cada incógnita

    Cada ecuación se reescribe dejando una sola incógnita a la izquierda:

    3 · Convergencia — dominancia diagonal

    Condición suficiente (no necesaria) para garantizar convergencia: en cada fila, el elemento diagonal debe superar en valor absoluto a la suma de los demás.

    4 · Convergencia — criterio de Sassenfeld

    Especialmente útil para Gauss-Seidel: β1 = (Σ|a1j|, j>1) / |a11|; para i>1, βi = (Σ|aij|βj, j<i + Σ|aij|, j>i) / |aii|. Si máx(βi) < 1, el método converge — y suele ser un criterio más útil que la dominancia diagonal, porque cubre casos donde esta no se cumple estrictamente.

    5 · Iterar

    Sesión 7 · Métodos iterativos

    Método de Jacobi-Richardson

    Es el mismo Jacobi (actualización simultánea, A = L + D + R), pero presentado desde la iteración de Richardson: se normaliza cada fila entre su propio pivote (a*ij = aij/aii) y el error se mide con la norma infinito de todo el vector, no incógnita por incógnita.

    1 · Sistema Ax = b

    2 · Despejar cada incógnita

    Cada ecuación se reescribe dejando una sola incógnita a la izquierda:

    3 · Convergencia — criterio de las líneas

    Con a*ij = aij / aii: si en cada fila Σ|a*ij| (j≠i) < 1, el método converge. Es la misma condición que la dominancia diagonal, expresada como fracción del pivote.

    4 · Convergencia — criterio de columna

    Alternativa cuando el criterio de las líneas no alcanza: se suma por columna en vez de por fila. Si máxj Σ|a*ij| (i≠j) < 1, el método también converge.

    5 · Iterar

    E = ‖x(k) − x(k−1)‖∞ / ‖x(k)‖∞ — un único error para todo el vector (el mayor cambio absoluto, dividido entre la mayor componente de la nueva iteración).

    Sesión 7 · Teoría de convergencia

    Convergencia — radio espectral ρ(T)

    Dominancia diagonal, Sassenfeld y los criterios de líneas/columna son condiciones suficientes: si se cumplen, garantizan convergencia, pero si fallan no prueban nada. El criterio definitivo (necesario y suficiente) es la matriz de iteración T: el método converge si y solo si ρ(T) — su radio espectral, el mayor módulo de sus valores propios — es menor que 1.

    1 · Sistema Ax = b

    2 · Elegir método y calcular ρ(T)

    ρ(T) se estima numéricamente con el método de la potencia (multiplicar T por un vector muchas veces y observar cuánto crece su norma) — el mismo enfoque práctico que sugiere la guía cuando pide "calcular o estimar ρ(T)". Con valores propios complejos dominantes se usa la media geométrica de varias iteraciones para que no oscile.

    3 · ¿Qué hacer si un criterio no se cumple?

    Si la dominancia diagonal (o Sassenfeld) falla, no concluyas "el método no converge" — solo significa que ese criterio no lo garantiza. Según la guía, el camino correcto es:

    1. Calcular la matriz de iteración T.
    2. Calcular o estimar ρ(T).
    3. Verificar si ‖T‖ < 1 (alguna norma matricial).
    4. En Gauss-Seidel, aplicar el criterio de Sassenfeld.
    5. Analizar experimentalmente la evolución del error o residuo iterando igual.

    Sesión 8 · Interpolación

    Interpolación lineal

    La forma más simple de interpolación: unir dos puntos vecinos con una línea recta. Cuanto más corto el intervalo entre esos dos puntos, mejor la aproximación — porque una función continua se parece más a una recta en tramos cortos.

    1 · Tabla de datos (x, y)

    2 · Elegir el par de puntos e interpolar

    f₁(x) = f(x₀) + (f(x₁) − f(x₀)) / (x₁ − x₀) · (x − x₀)

    Sesión 8 · Interpolación

    Interpolación polinómica — sistema de Vandermonde

    Dados n+1 puntos, existe un único polinomio Pn(x) = a₀ + a₁x + ⋯ + aₙxⁿ de grado ≤ n que pasa por todos ellos. Sus coeficientes se obtienen resolviendo el sistema lineal Pn(xi) = yi, cuya matriz de coeficientes es la matriz de Vandermonde: si los xi son distintos, det V ≠ 0 y la solución es única.

    2 · Sistema de Vandermonde V·a = y

    Cada fila i es [1, xi, xi², …, xiⁿ] — los coeficientes a₀…aₙ son las incógnitas.

    Sesión 9 · Interpolación

    Interpolación de Newton — diferencias divididas

    A diferencia de Lagrange, pasar de grado n a grado n+1 solo exige añadir un término más: no se rehace nada. Los coeficientes son las diferencias divididas f[x₀], f[x₀,x₁], f[x₀,x₁,x₂], … — la primera fila de cada columna de la tabla — y el polinomio es Pn(x) = Σ f[x₀,…,xk]·Π(x − xj).

    1 · Tabla de datos (x, f(x))

    2 · Grado a usar y punto a evaluar

    Si eliges un grado menor que n, se usan los puntos consecutivos más cercanos a x (el polinomio "apropiado" del ejercicio de la guía).

    Sesión 9 · Errores en la interpolación

    Error de truncamiento por interpolación

    En los nodos Pn(xk) = f(xk), pero en cualquier otro x aparece un error En(x) = f(x) − Pn(x) = (x−x₀)⋯(x−xn)·f(n+1)(ξ)/(n+1)!. Solo se puede acotar cuando se conoce la expresión analítica de f(x): |En(x)| ≤ Π|x−xi|/(n+1)! · máx|f(n+1)(t)|.

    1 · Función conocida y nodos

    Usa x, + − * / ^, paréntesis y las funciones sin, cos, tan, exp, ln (natural), log (base 10), sqrt; constantes pi y e. Ejemplo: exp(x) − x^2 + 1
